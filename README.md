# Student Management System

A simple Student Management System built as part of a DevOps assignment, demonstrating CI/CD with GitHub Actions and Agile planning with Jira.

## Features
- Add a student
- View all students
- Delete a student

## Tech Stack
- Python 3.11
- GitHub Actions (CI/CD)
- Jira (Agile planning)

## How to Run
```bash
python app.py
